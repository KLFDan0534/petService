# 前端旧样式改写交接文档

> 用途：把下面列出的「仍在使用旧设计令牌(`--color-*` / `--radius-*` / `--shadow-*` / `--space-*` / `--font-*`)」的组件与页面，改写成与已完成改造页面一致的新设计体系(`--ref-*` 米色暖调)。
> 只改**前端**；**后端 API 与数据库一律不动**。前端 API 封装位于 `frontend/src/api/*`，状态管理位于 `frontend/src/stores/*`，均保持现有函数与签名不变，仅在改写样式/模板时继续引用。

---

## 0. 判断规则（接收方必读）

- **已完成新版**的参考页面：`views/user/Dashboard.vue`、`views/user/Orders.vue`、`views/order/OrderDetailView.vue`、`views/user/Services.vue`、`views/user/ServiceDetail.vue`、`views/user/Profile.vue`。改样式时直接参照它们，`--ref-*` 令牌、Section/卡片/按钮/弹窗写法照搬。
- **每列一个文件的「状态」**：`old令牌=N` 表示该文件仍是旧样式(需要改写)；`ref令牌=N` 是已用新令牌数量。
- 改写 = **重写 `<template>` 与 `<style scoped>`，`<script setup>` 逻辑与 `@/api` / `@/stores` 导入原样保留**（除非明显冗余）。
- 验收标准：页面不再出现橙色/白色/蓝色的 shadcn 旧观感，视觉与 `Dashboard.vue` 统一；无裂图、无错位。

## 1. 设计令牌对照表（旧 → 新）

旧令牌当前仍定义在 `src/assets/css/design-tokens.css`（:root 橙色主题），**建议替换为下列新令牌**：

| 旧令牌（删除） | 替换为新令牌 |
|---|---|
| `--color-background` | `var(--ref-canvas)` |
| `--color-card` / `--color-card-foreground` | `var(--ref-surface)` / `var(--ref-ink)` |
| `--color-foreground` | `var(--ref-ink)` |
| `--color-foreground(次要)` | `var(--ref-ink-soft)` |
| `--color-muted` | `var(--ref-sand)` |
| `--color-muted-foreground` | `var(--ref-muted)` |
| `--color-border` | `var(--ref-line)` |
| `--color-primary` / `--color-primary-foreground(on-primary)` | `var(--ref-brand)` / `#fff` |
| `--color-ring` / `--color-accent` | `var(--ref-brand)` / `var(--ref-brand-deep)` |
| `--color-secondary` | `var(--ref-cream)` |
| `--color-danger` / `--color-error` / `--color-destructive` | `#A03422`（深锈红） |
| `--color-success` | `#3E7C5B` |
| `--color-warning` | `#C98A2D` |
| `--color-info` | `#4A72A8` |
| `--radius-sm(--6px)` | `10px` |
| `--radius-md(--12px)` | `12px` |
| `--radius-lg(--16px)` | `16px` |
| `--radius-xl(--24px)` | `18px` |
| `--radius-full` | 保留 `9999px` |
| `--shadow-sm/md/lg/xl` | 改为暖调柔和阴影：`0 1px 2px rgba(36,28,20,.06)`、`0 8px 24px -12px rgba(36,28,20,.18)` 等 |
| `--font-heading`/`--font-body` | 正文默认 sans-serif；大标题用 `var(--ref-font-display)`（衬线 Serif） |
| `--font-mono` | 保留等宽 `ui-monospace,...` |
| `--space-xs~3xl` | 可继续用数值，不强制 |

新令牌官方定义（`--ref-*`）：

```
--ref-canvas:#FBF7F0; --ref-surface:#FFFFFF; --ref-sand:#F1E9DB; --ref-cream:#F6EFE3;
--ref-line:#E9DFCD; --ref-ink:#241C14; --ref-ink-soft:#55463A; --ref-muted:#8A7A6A;
--ref-brand:#BF5B2B; --ref-brand-deep:#9A411A;
--ref-font-display:'Noto Serif SC','Songti SC','STSong','SimSun',Georgia,'Times New Roman',serif;
（含 dark 主题下对应深色值，见 design-tokens.css html[data-theme=dark]）
```
