## 第一部分 · 任务要求

### 1. 任务概述

把本文件「第六部分」列出的 **36 个用户端页面**，统一改造为**暖色编辑风（Editorial Warm）**视觉风格。参考标准为「第二部分」的设计令牌，以及已完成的 5 个示例页面（本文件第五部分全文内联，供风格对照）。

### 2. 硬性要求（接手 AI 必须遵守）

1. **不改后端、不改接口语义、不改路由**：数据字段一律保持 `*_wsh` 后缀原样，API 调用逻辑、接口地址、字段名一个都不能改。
2. **完整适配，不要硬编码**：所有颜色 / 圆角 / 阴影 / 间距优先引用 `--ref-*` / `--color-*` 设计令牌；确需强调色时用 `color-mix(in srgb, ...)` 组合语义色，禁止页面内散落十六进制色值。
3. **保留全部功能与交互**：表单校验、弹窗、分页、状态流转、权限判断、加载 / 错误 / 空态骨架屏等逻辑与交互一个都不能少，只改视觉呈现，不重构。
4. **响应式**：用 CSS Grid / Flex + `clamp()` 与媒体断点（参考示例页约 `1100px / 900px / 760px / 520px`），移动端网格降列、间距收窄，不横向溢出。
5. **主题**：暗色模式由全局 `html[data-theme="dark"]` 自动切换令牌，页面内不要写死暗色覆盖（除非少数「明暗都保持深色」的强调块，参考 Dashboard 的 `.db-dark` 写法）。
6. **完成后自检**：`npm run build` 通过；无 `_ctx.xxx is not a function` 类运行时错误；明暗双主题均正常。

### 3. 视觉语言要点

- 底色 `--ref-canvas`，卡片 `--ref-surface` + `--ref-line` 描边，圆角用 `--radius-*`。
- 大标题用衬线字体 `--ref-font-display`（Noto Serif SC 等），正文用全局无衬线。
- 分区小节带编号眉题（如 `01` / `02`）+ 英文小标（如 `Pet Profiles`）+ 分隔线，参考示例 Profile 页 `ps-eyebrow` 结构。
- 状态徽章用 `badge badge-{tone}`（tone：`action / active / done / closed / queued`）。
- 按钮：主按钮 `cta cta-primary`、次按钮 `cta cta-outline`、深色按钮 `cta cta-dark`、文字链接 `text-link`。
- 图片缺省用 `MediaWithFallback` 组件。
- 滚动进场动画用 IntersectionObserver + `transitionDelay` 错峰，尊重 `prefers-reduced-motion`。

### 4. 改造建议流程

1. 先读「第二部分」设计令牌与「第五部分」示例页（推荐 `Profile.vue`、`Services.vue`）掌握风格。
2. 通读「第四部分」API 接口层，确认字段与请求方式。
3. 逐页改造「第六部分」页面，每页改造后对照其「API 依赖」核对接口调用未被改动。

## 第二部分 · 设计系统

### 2.1 核心令牌速查（暖色编辑风）

| 令牌 | 亮色值 | 用途 |
|---|---|---|
| `--ref-canvas` | `#FBF7F0` | 页面底色（米白） |
| `--ref-surface` | `#FFFFFF` | 卡片 / 面板表面 |
| `--ref-sand` | `#F1E9DB` | 次级底 / 占位 |
| `--ref-cream` | `#F6EFE3` | 强调底 |
| `--ref-line` | `#E9DFCD` | 描边 / 分隔线 |
| `--ref-ink` | `#241C14` | 主文字（暖黑） |
| `--ref-ink-soft` | `#55463A` | 次级文字 |
| `--ref-muted` | `#8A7A6A` | 弱化文字 / 说明 |
| `--ref-brand` | `#BF5B2B` | 品牌橙（陶土色） |
| `--ref-brand-deep` | `#9A411A` | 品牌深橙（hover） |
| `--ref-font-display` | Noto Serif SC 等衬线 | 标题 / 数字字体 |

暗色主题由 `html[data-theme="dark"]` 自动切换上述令牌，无需在页面内处理。
